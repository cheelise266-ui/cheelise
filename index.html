Guide Complet : Héberger votre Site & Vidéos GRATUITEMENT

Vous souhaitez un site complet avec des vidéos indépendantes (sans le logo YouTube, les suggestions parasites ou le tracking de Vimeo) sans rien payer ? Voici les meilleures solutions modernes et gratuites.

Étape 1

Où Stocker/Héberger vos Fichiers Vidéo MP4 ?

1 Internet Archive (Archive.org)

100% Gratuit & Illimité

Créez un compte gratuit sur Archive.org, uploadez votre fichier MP4. Une fois traité, copiez l'URL directe du fichier MP4. C'est la solution la plus populaire pour héberger gratuitement des vidéos publiques sans limite de bande passante.

2 Cloudinary (Offre Free)

25 Go Gratuit/Mois

Inscrivez-vous sur Cloudinary.com. Téléversez vos vidéos et obtenez des URLs de streaming optimisées ultra-rapides. Parfait pour une qualité vidéo professionnelle HD/4K.

3 Supabase / Firebase Storage

1 Go gratuit

Hébergez directement vos fichiers vidéos dans un bucket public sur Supabase ou Firebase et utilisez l'URL publique fournie.

4 GitHub Repository (Vidéos légères)

< 25 Mo par vidéo

Si vos vidéos font moins de 25 Mo, déposez-les directement dans le même dossier que votre fichier `index.html` (ex: `video/intro.mp4`).

Étape 2

Où Héberger votre Site Web (index.html) ?

GitHub Pages

100% Gratuit, nom de domaine `votre-nom.github.io` inclus + HTTPS SSL.

  1. Créez un dépôt sur Github.com
  2. Uploadez le fichier index.html exporté
  3. Allez dans Settings > Pages > Sélectionnez la branche main
  4. Votre site est en ligne en 1 minute !

Netlify / Vercel

Glissez-déposez simplement votre dossier pour publier instantanément.

  1. Créez un compte gratuit sur Netlify.com
  2. Glissez votre dossier contenant index.html
  3. Site publié instantanément avec adresse gratuite !
